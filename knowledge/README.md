# 合成企业制度语料

本目录中的文档均为项目构造的脱敏评测材料，不对应任何真实公司、员工或内部制度。

## 元数据约定

每份 Markdown 文件必须使用 YAML front matter，并包含：

- `document_id`
- `title`
- `document_type`
- `department`
- `visibility`
- `allowed_roles`
- `version`
- `status`
- `effective_from`
- `effective_to`
- `supersedes_id`
- `source_path`

文档内容中的二级和三级标题会成为引用的 `section_path`。金额、时限和审批角色只在正文中定义，测试题不得把答案直接写入元数据。
