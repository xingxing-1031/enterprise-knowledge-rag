# W4-2：结构化回答、引用校验与拒答

## 本阶段目标

要求回答中的每个事实绑定真实证据，并在金额、时限和审批角色不受证据支持时阻止输出。

## 业务问题

模型即使拿到了正确证据，也可能写错数字、混入其他版本的审批角色，或者引用不存在的片段。只在 Prompt 中说“不要编造”不能保证结果正确。

## 我的实现

回答模型输出结构化 `DraftAnswer`，每条 claim 必须列出 `evidence_id`。代码校验引用是否存在，并检查 claim 中的数字、日期单位和关键审批角色是否出现在引用原文。第一次失败允许重新生成一次；再次失败时不返回错误自然语言，而是降级展示已验证证据摘要。

## 验证结果

- 结构化生成、引用校验、有限重生成和拒答专项测试：9 项通过。
- 全部 Python 回归：60 项通过，1 项 pgvector 环境测试明确跳过。
- 测试覆盖未知引用、无依据数字、错误审批角色、第二次生成成功和连续失败后可信降级。

## 遇到的问题与取舍

引用校验目前确定性覆盖金额、数量、时间单位和关键审批角色；长段语义是否忠实仍不能只靠字符串规则判断，后续评测会单独增加答案正确性评审，不把引用存在等同于完整答案正确。

## 我能口述的标准答案

RAG 召回正确不等于答案正确。模型可能把15天写成30天，或者把直属主管写成总经理。因此我让模型返回 claim 和 evidence_id，再用代码核对引用是否存在，并检查关键数字和审批角色是否能在原文中找到。校验两次失败后只返回可信证据摘要，不让表达层错误污染核心事实。
