# W1-1：项目二基础与领域模型

## 本阶段目标

建立可复现的 Python 工程和企业 RAG 的共享数据契约。

## 业务问题

企业制度不能只按一段文本返回。系统必须知道文档属于哪个部门、哪个版本、何时生效以及当前用户能否访问。

## 我的实现

使用 Pydantic 严格模型约束文档、文档片段、用户上下文、召回候选和检索证据。使用环境变量配置模型、数据库和部署参数，避免旧项目的本机绝对路径。

## 验证结果

本阶段完成后填写实际 pytest、Ruff 和包构建结果。

## 遇到的问题与取舍

先建立确定性数据契约，再接入向量库和大模型，避免把业务边界交给 Prompt。
